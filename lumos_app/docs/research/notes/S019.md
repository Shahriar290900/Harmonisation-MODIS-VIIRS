# S019 - MCD64A1 V6.1 DOI landing (10.5067/MODIS/MCD64A1.061)
Fetched 2026-10-10: doi.org 302 -> https://www.earthdata.nasa.gov/data/catalog/lpcloud-mcd64a1-061 (HTTP 200; relayed by summarising model).

VERIFIED FACTS
1. Title: "MODIS/Terra+Aqua Direct Broadcast Burned Area Monthly L3 Global 500m SIN Grid V061" (MCD64A1). Temporal coverage 2000-11-01 to present, monthly; published/updated 2021-04-08.
2. Algorithm: 500 m MODIS surface reflectance plus "1 kilometer (km) MODIS active fire observations"; burn-sensitive vegetation index with dynamic thresholds; burn date stored as ordinal day.
3. Citation: Giglio, L., Justice, C., Boschetti, L., & Roy, D. (2021). NASA LP DAAC. DOI 10.5067/MODIS/MCD64A1.061.
4. V6.1 changes are input-side only: Level-1B calibration improvements (Aqua/Terra response-versus-scan-angle, Terra IR crosstalk, Terra forward LUT corrections 2012-2017) and a polarization correction.
5. Docs: User Guide https://lpdaac.usgs.gov/documents/1006/MCD64_User_Guide_V61.pdf ; ATBD https://lpdaac.usgs.gov/documents/115/MCD64_ATBD_V6.pdf ; known issues via landweb.modaps.eosdis.nasa.gov (not fetched).
6. No overpass times given on this page.

USE IN PROJECT: Provenance string for the validation layer; confirms (second source after S007) that MCD64A1 depends on MODIS active fires. The 2021 citation year is the product-version citation, distinct from the 2018 RSE algorithm paper (S015, not read).
