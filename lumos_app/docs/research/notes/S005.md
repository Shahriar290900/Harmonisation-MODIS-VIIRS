# S005 - Earth Engine catalog: GlobFire v2 Final Perimeters (JRC/GWIS/GlobFire/v2/FinalPerimeters)
Fetched 2026-10-10 from https://developers.google.com/earth-engine/datasets/catalog/JRC_GWIS_GlobFire_v2_FinalPerimeters (HTTP 200; relayed by summarising model). The companion paper row S017 (Sci Data) was BLOCKED, so event-definition rules below are only what this catalog page says.

VERIFIED FACTS
1. Title "GlobFire Final Fire Event Detection Based on MCD64A1"; availability 2001-01-01 to 2021-01-01 (UTC). It ends 2021: no coverage for 2022-2026.
2. Fields: `area` (DOUBLE, m2), `Id` (INT), `InitialDate`, `FinalDate` (INT, ms since 1970-01-01).
3. Perimeters derived from MODIS MCD64A1; method represents the "space-time relationship among patches of burned areas" as a graph; each event has a unique number. Minimum fire size not stated on the page.
4. Licence CC-BY-4.0. Provider EC JRC / GWIS. Citation: Artes, Oom, De Rigo, Durrant, Maianti, Liberta, San-Miguel-Ayanz (2019), "A global wildfire dataset for the analysis of fire regimes and fire behaviour", Scientific Data 6(1), 1-11, DOI 10.1038/s41597-019-0312-2.

CAVEATS: Built from MCD64A1, so not independent of MODIS active fires. Ends 2021.

USE IN PROJECT: Optional event-level check of seasonal timing (InitialDate/FinalDate) for 2001-2020 inside an AOI. It is MODIS-based, so it cannot arbitrate MODIS vs VIIRS differences; say "consistency check" in the UI.
