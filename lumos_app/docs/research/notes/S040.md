# S040 JasmineW6214/wildfire README
Fetched 2026-10-10 by R4 via WebFetch (HTTP 200, summariser output).

## Verified facts
1. Region-configurable pipeline of 11 GEE notebooks producing model-ready wildfire detection/prediction datasets (not a prebuilt dataset). Default region Alberta, Canada via `FAO/GAUL/2015/level2`; "not yet validated worldwide".
2. GEE IDs it uses: `MODIS/061/MOD11A1` (LST 1 km daily), `ECMWF/ERA5_LAND/HOURLY` (~9 km), `NASA/VIIRS/002/VNP13A1` (NDVI 500 m), `USGS/SRTMGL1_003`, `MODIS/061/MCD12Q1` (LC_Type1, yearly 500 m). Fire target: FIRMS (no full ID given), fields T21 and confidence.
3. Grid: 1 km x 1 km, daily, EPSG:4326 (we use a 5 km equal-area grid x month; theirs is geographic lat/lon, so cell area varies with latitude).
4. Labels: fire is "under 2% of samples" (class imbalance, rebalanced). Window 15 days; detection (offset 0) and prediction (offset 15) datasets; 14 features; output `.npz` e.g. `sequences_y2019-2024_w15_o0_r4.npz`. Advice: run one year at a time to stay inside GEE free-account task limits.
5. Licence: scripts/docs CC-BY-4.0; source datasets keep their terms (ERA5-Land under Copernicus licence).

USE IN PROJECT: only as an idea source for optional covariates (land cover from MCD12Q1, which R3 found covers 2001-2024 only). It is a fire-prediction pipeline, not cross-sensor harmonization; do not frame our work as prediction. No reuse.
