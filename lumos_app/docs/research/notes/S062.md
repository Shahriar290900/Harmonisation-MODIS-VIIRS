# S062 - geoBoundaries API documentation (geoboundaries.org/api.html)
Fetched 2026-10-10 (HTTP 200 this time; earlier robots-block noted in the ledger did not recur). Relayed by summarising model.

VERIFIED FACTS
1. Endpoint pattern: `https://www.geoboundaries.org/api/current/[RELEASE-TYPE]/[ISO3]/[ADM-LEVEL]/`; RELEASE-TYPE in gbOpen, gbHumanitarian, gbAuthoritative; ADM0-ADM5 or ALL. Bangladesh ADM2 would be `.../gbOpen/BGD/ADM2/` (INFERRED from the pattern; page has no BGD example; not tested, no fetch of the API itself).
2. Response is JSON with links: `staticDownloadLink` (zip), `gjDownloadURL` (geoJSON), `tjDownloadURL` (topoJSON), simplified geoJSON, `imagePreview`.
3. Licences: each record has `boundaryLicense` (source's original licence) and optional `licenseDetail`. gbOpen = "CC-BY 4.0 compliant"; gbHumanitarian (from UN OCHA) "may have less open licensure"; gbAuthoritative (from UN SALB) "cannot be used for commerical purposes" [sic].
4. Archived releases listed: 5.0.0 (19 Dec 2022), 4.0.0, 3.0.0, 2.0.0, 1.3.3.
5. No rate limits stated; automated use encouraged but "we cannot guarantee uptime for our API". Attribution required.

USE IN PROJECT: Only use gbOpen, never gbAuthoritative (non-commercial). Keep Natural Earth as the default (offline, no uptime risk); geoBoundaries only as an optional ADM2 source for Bangladesh, vendored into the repo with attribution rather than fetched live.
