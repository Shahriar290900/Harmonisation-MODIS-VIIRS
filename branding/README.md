# Branding (mockups)
- `parallax-fire-logo.svg` / `parallax-fire-mark.svg`: project logo. Two overlapping views (cyan = the older satellite, MODIS; violet = the sharper one, VIIRS) with a flame where they meet: same fires, two cameras, one honest record.
- `lumos-team-logo.svg`: Team Lumos logo. "Lumos" means light: a rayed light source.
- `*.png`: rendered on the dark background used by the app (for slides, the submission form and the video).
Mockups made for NASA Space Apps Challenge 2026; colours follow `parallax_app/docs/UI_DESIGN_BRIEF.md`.
