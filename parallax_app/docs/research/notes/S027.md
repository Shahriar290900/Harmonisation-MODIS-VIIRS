# S027 | FIRMS Area API page
URL: https://firms.modaps.eosdis.nasa.gov/api/area/ | fetched 2026-10-10 via WebFetch (tool summary with quotes) | HTTP: fetched OK

## What it is
Documentation of the Area API (CSV by source, bbox, day range, optional date). Needs a MAP_KEY (we have none and never request one).

## Verified facts (seen 2026-10-10)
1. URL pattern: "/api/area/csv/[MAP_KEY]/[SOURCE]/[AREA_COORDINATES]/[DAY_RANGE]" returns the most recent data; adding "/[DATE]" returns data starting from a given date.
2. SOURCE values listed: LANDSAT_NRT, MODIS_NRT, MODIS_SP, VIIRS_NOAA20_NRT, VIIRS_NOAA20_SP, VIIRS_NOAA21_NRT, VIIRS_SNPP_NRT, VIIRS_SNPP_SP. There is NO NOAA21_SP; NOAA-21 is offered only as "VIIRS NOAA-21 (URT+NRT)". Matches SOURCE_CHECK #1.
3. Bounding box order: west,south,east,north (example "-85,-57,-32,14"); "world" = [-180,-90,180,90].
4. DAY_RANGE: allowed 1 through 5 ("number of days to query at one time"). The brief's "1-10" is NOT on the live page: the cap is 5. Pack and SOURCE_CHECK are right.
5. DATE: "YYYY-MM-DD", optional; omitted gives the most recent data. The page points to /api/data_availability/ for date availability.
6. Cost rule: "Larger transactions may count as multiple requests (ex. requesting 7 days)." (The example of 7 days sits oddly next to the 1-5 cap; quote as-is.)
7. Rate limit: "MAP_KEY limit is 5000 transactions / 10-minute interval." and "Contact us if you need limit increase."
8. Only CSV output is shown.

## Caveats
- The page text does not say how a bbox size changes the cost; only the day-count example is given.
- No LANDSAT or NOAA21_SP assumptions should be baked into the ingest code.

USE IN PROJECT: CONTRACT `{1..5}` day range is correct; for a longer NRT window loop 5-day chunks sequentially and count each as one-or-more transactions.
USE IN PROJECT: NOAA-21 NRT in the Area API has no SP counterpart; the NRT panel may use VIIRS_NOAA20_NRT/VIIRS_NOAA21_NRT after S-NPP ends.
USE IN PROJECT: never ship a MAP_KEY in the static PWA; if a live panel is wanted, use a pre-fetched snapshot or a server-side key (owner decision).
