## Verified facts (README as summarised)
1. Shows "Worldwide fire data (375m resolution) as detected by NASA/NOAA VIIRS (Suomi polar orbit) and MODIS (1km resolution)" with USGS/GeoMAC fire boundaries "updated daily".
2. Pipeline: "The CSVs are being pulled into a HERE XYZ Space every 20 minutes and cut into vector tiles on the fly." HERE XYZ is a hosted service; a hosted tile server is not an option for a static PWA. Hosting of the page itself: GitHub Pages.
3. Time UX: legend slider sets the time span of each colour step in hours; Viridis ("White dots are the latest data, yellow the steps before..."); animation view "broken right now".
4. Overpass claims (third-party README, NOT a NASA source): VIIRS passes "every ~12 hours", typically 1-3 AM and 1-3 PM for California; Terra ~10:30 am and 10:30 pm; Aqua ~1:30 pm and 1:30 am. Partial support for Terra morning / Aqua afternoon; S-NPP ~13:30 is consistent with "1-3 PM". Still not a primary source: keep UNVERIFIED until a NASA page quotes it.
5. README does not discuss deduplication; says overlapping passes can yield an extra set of data.
6. Licence not stated in the fetched content.
