## Verified facts (README, as summarised)
1. Purpose: code and data to process and cluster MODIS and VIIRS fire detections, e.g. "persistent combustion sources (flares, burn pits, wildfires)". Accompanies Franklin et al. (2025), Journal of Exposure Science & Environmental Epidemiology.
2. Inputs: NASA FIRMS, MODIS MCD14ML and VIIRS VNP14IMG; example file names `fire_archive_M-C61_*.csv` (MODIS) and `fire_archive_SV-C2_*.csv` (VIIRS). No years stated.
3. Preprocessing: convert to a spatial format and project to local UTM zones. README does NOT describe filtering by `type` or confidence.
4. Clustering: HDBSCAN ("hierarchical density based scanning") with "Adjustable minPts values for tuning". NO numeric minPts or min_cluster_size on the README page (the question R1 asked: unanswered by the README; would need the R scripts, which are out of scope for README-only fetches).
5. Persistence: detections are clustered annually to identify persistent sources; the README does not say how persistence is measured beyond that.
6. Outputs: annual spatial clusters and comparisons across years, regions and satellite products; formats not described.
7. Licence MIT. Language R (packages sf, dbscan, tidyverse, doParallel, foreach).
