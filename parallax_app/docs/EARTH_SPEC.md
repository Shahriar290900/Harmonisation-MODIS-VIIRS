# Earth dashboard (Live page) — spec, 13 Nov 2026
Owner request: "a proper dashboard showing the whole Earth, the globe, satellite simulations using three.js, satellites floating around Earth in real time, proper terrain, textures; GSAP for animation; clean, not jargon-heavy." Rapier is deliberately NOT used: satellites must follow their real orbits (SGP4 from CelesTrak records), a physics engine would make the motion fake. Binding: CLAUDE.md, docs/REVAMP_SPEC.md (plain language, real data only, honesty), docs/LIVE_SOURCES.md, docs/UI_DESIGN_BRIEF.md. Check: `node scripts/goals/goal_earth.mjs <shots>`.

## What the user sees (#/live, default view "Earth")
A full-width, tall (≥ 70vh desktop, ≥ 60vh phone) three.js Earth, dark space background, calm and precise:
- **Earth:** real NASA imagery as the day texture (Blue Marble), real night-lights texture on the night side, a terrain/elevation map for relief (bump), a water mask for ocean specular glint, a thin atmosphere glow (fresnel). Day/night boundary from the real sun position at the current UTC time (subsolar point), updated every few seconds.
- **Satellites:** Terra, Aqua, Suomi NPP, NOAA-20, NOAA-21 at their real positions now (satellite.js SGP4 from `/api/sats`), moving in real time (true speed; ~7 km/s, one orbit ≈ 99–101 min), each with a small model/marker, a label, and its orbit path (next ~100 min ahead, faint trail behind). Older satellite (MODIS: Terra, Aqua) in the MODIS colour, sharper (VIIRS) in the VIIRS colour.
- **Hot spots:** today's NASA FIRMS detections (last 24 h, `/api/firms-live?scope=world`), drawn as small glowing points on the surface (GPU points, one draw call; downsample on phones), coloured by satellite group; "a hot spot is not a confirmed wildfire" stays in a tooltip/legend line.
- **HUD (gods-eye-view spirit, re-created):** corner brackets, UTC clock, a compact legend, per-satellite cards (name, height km, speed km/s, "over: <country/sea>" if cheaply derivable, else lat/lon, next pass over the selected place — computed), hot-spot counts per satellite group (never summed into one number), feed time. Minimal words.
- **Interaction:** drag to rotate, scroll/pinch to zoom (OrbitControls with damping), click/tap a satellite to follow it (camera tracks it), quick jumps Bangladesh / California / New South Wales / Whole Earth with GSAP camera tweens (cubic-in-out ~1.6 s; reduced motion → instant), gentle auto-rotation when idle (off under reduced motion), layer toggles: hot spots, orbits, night lights, labels. Keyboard accessible controls; the canvas has an aria-label and a visually hidden live summary.
- **Map view:** a `[data-live-view="map"]` tab switches to the existing detailed MapLibre view (current Live page content: imagery, layer panel, looks menu); `[data-live-view="earth"]` switches back. Selection stays in the URL.
- Optional, only if verified working and fast: a "Yesterday's real Earth" day texture from NASA GIBS WMS (EPSG:4326 whole-world GetMap, MODIS Terra or NOAA-20 true colour, yesterday's UTC date), labelled with its date.

## Real data and assets
- Textures must be real NASA products, downloaded once into `apps/web/public/textures/` with `SOURCES.md` (URL, product, licence: NASA imagery is public domain; credit "NASA Visible Earth / Blue Marble, Black Marble"). Prefer NASA Visible Earth originals (Blue Marble Next Generation with topography/bathymetry, Black Marble 2016 night lights, a GEBCO/SRTM-derived elevation map) resized with ffmpeg (static binary at `<scratchpad>/vid/node_modules/ffmpeg-static/ffmpeg`) to ≤ 4096×2048; total ≤ 4 MB. If an original is unavailable, use the NASA-derived maps from the three-globe example images (unpkg `three-globe@2.x/example/img/`) and say so in SOURCES.md. Download politely (one at a time, no retries in a loop).
- Stars in the background are decorative (label nothing as data).
- No invented positions, counts or times. If a feed is down, show the honest unavailable state (no satellites → "orbit records unavailable"; no hot spots → "feed unavailable", never zero).

## Engineering
- Lazy-loaded chunk (three.js + satellite.js + textures only load on #/live). Dispose renderer, geometries, textures, controls, timers and listeners on leave. Pause rendering when the tab is hidden or the view is off screen; cap pixel ratio (2 desktop, 1.5 phone); quality tier for phones (fewer segments/points, no glint).
- Coordinates: Earth-fixed frame; lat/lon/alt → xyz on a sphere of radius R (alt scaled realistically, e.g. 1 + alt/6371, optionally ×1.5 for visibility, stated in a code comment); sun direction from the subsolar point in the same frame (night shader uses dot(normal, sunDir)).
- Debug contract (dev and prod; cheap): `window.__earth = { debug(): { ready, textures:{day,night,bump}, frames, hotspots, sats:[{name, lat, lon, altKm}], sun:{lat, lon} } }`, values from the same state the renderer uses. `frames` = frames rendered.
- Satellite names exactly: "Terra", "Aqua", "Suomi NPP", "NOAA-20", "NOAA-21" (as `/api/sats` returns them).
